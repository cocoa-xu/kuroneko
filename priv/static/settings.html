Settings

How this NanoKVM-Go reaches your network, and who may log in to it.

Wi-Fi

–

The list keeps each network for five minutes after it was last seen, and looks again every ten seconds while this page is open. The country sets the channels and transmit power the Wi-Fi may use; changing it restarts the Wi-Fi. With a passphrase the NanoKVM-Go takes WPA2, or WPA3 where a network offers nothing else. Networks that need a user name too, and WEP, are not supported here. Over USB the page stays reachable whatever the Wi-Fi does.

SSH

An Elixir shell (IEx) on the device, and firmware updates. Log in with any user name and this page's password, or with a key below.

ssh nerves.local

Add keys

Public keys, one per line, as in ~/.ssh/id_ed25519.pub. The device keeps them across firmware updates.

Password

For this page and SSH. Changing it ends the other sessions of the page.

Join a network

This page came over Wi-Fi: it goes away while the NanoKVM-Go changes networks. Its screen then shows its new address; over USB it stays where it is.
